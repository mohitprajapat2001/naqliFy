### 🏷️ **Project Name:** NaqliFy

### 🧾 **Short Description:**

**NaqliFy** is a developer-focused API service built with Django Rest Framework that delivers high-quality fake data for testing and prototyping — with a uniquely Indian twist.

---

### 📜 **Full Description:**

### 💡 **Key Features:**

- 🔄 RESTful APIs for quick mock data generation
- 🏷️ Easy endpoints like `/api/airlines/`, `/api/people/`, `/api/cars/`
- 🌍 Localized (with optional Indian-style data)
- ⚙️ Customizable fields and batch generation
- 📦 Plug and play for frontend/backend devs and QA teams
